# Owner
The Owner Page displays the managing owner. It shows what properties the managing over manages, and it allows you to edit the owner!

![Docs Version Dropdown](./img/owner.png)

You can edit the owner with the edit button! The Edit Button will take you to [Create Person](./Person.md) page where you can edit the owner details!

![Docs Version Dropdown](./img/owner2.png)
